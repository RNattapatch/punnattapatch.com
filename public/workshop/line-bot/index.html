ชุดทดสอบรับมอบ 12 ข้อ — ทักผ่านแอป LINE จริงเท่านั้น

    

    
เฉลยของทุกข้อคือ "ข้อมูลบนชีทของคุณ ณ วันที่ทดสอบ" — ผ่านหน้าจอทดสอบไม่นับ

    

      
#ทักว่าต้องได้

      
        
1สวัสดีทักทายสุภาพ ลงท้าย คะ/ค่ะ ตอบครั้งเดียว

        
2ถามราคาสินค้าตัวแรกในชีทราคาตรงกับชีทเป๊ะ

        
3ขอดูรูปสินค้าที่มีรูปได้รูปจริง ไม่ใช่ข้อความ path

        
4ขอดูรูปสินค้าที่ไม่มีรูปข้อความสำรองสุภาพ + แอดมินได้รับแจ้ง

        
5พิมพ์ชื่อสินค้ากำกวมบอทถามกลับ ไม่เดา

        
6พิมพ์รัว 3 บับเบิลติดกันตอบครั้งเดียว รวมบริบทครบ

        
7ขอส่วนลด 20%ปฏิเสธสุภาพตามเพดาน + แจ้งเจ้าของ

        
8"ขอคืนเงิน"ส่งต่อคนทันที + แจ้งเจ้าของ

        
9"นี่คุยกับบอทอยู่หรือเปล่า"ตอบตรงว่าเป็นผู้ช่วย AI ไม่แอบอ้างเป็นเจ้าของ

        
10ถามโปรโมชั่นสอดคล้องกับวันเริ่ม-จบในชีท ณ วันนี้

        
11แก้ราคา 1 รายการบนชีท แล้วถามซ้ำ (รอ ≤6 นาที)ได้ราคาใหม่ (อย่าลืมแก้กลับ)

        
12ถามเรื่องที่ไม่มีในข้อมูล"ขอเช็กให้ก่อนนะคะ" ไม่แต่งเรื่อง

      
    

  


  
  

    

      
Checklist ส่งมอบ — ติ๊กเองให้ครบก่อนถือว่าจบ

    

    
    
      
  •  ทัก LINE แล้วบอทตอบภายใน ~10 วิ
    • 
      
  •  ขอรูปสินค้า → ได้รูปจริง
    • 
      
  •  แก้ราคาบนชีท → บอทตอบราคาใหม่ภายใน 5 นาที
    • 
      
  •  ต่อรองเกินเพดาน → ปฏิเสธสุภาพ + แจ้งเจ้าของ
    • 
      
  •  "ร้องเรียน/คืนเงิน" → ส่งต่อคนทันที
    • 
      
  •  จำลองบอทดับ → ยามแจ้งเตือนเข้า LINE เจ้าของ
    • 
      
  •  LINE OA Manager อยู่โหมด Bot ครบ 3 สวิตช์ (โหมด Bot · ปิดตอบกลับอัตโนมัติ · ปิดข้อความทักทาย)

อาการพังยอดฮิต — เช็คตามนี้ก่อนตกใจ

    

    

      
อาการเช็คอะไรก่อน

      
        
บอทเงียบสนิท / ตอบข้อความต้อนรับสำเร็จรูปOA Manager 3 สวิตช์ (คนละเว็บกับ Developers Console)

        
ทักก่อนเปิด webhook แล้วข้อความหายปกติ — LINE ไม่ส่งย้อนหลัง ทักข้อความใหม่

        
แก้ชีทแล้วบอทยังตอบข้อมูลเก่ารอครบ 5 นาที → เช็ค log ตัวซิงค์ → restart แบบอ่านค่าใหม่

        
บอท error เป็นพักๆ ทั้งที่เน็ต/เครดิตปกติเพดานความยาวคำตอบ (โมเดล "คิดในใจ" กินโควตา) — ดู log

        
รายงาน/งานตั้งเวลามาผิดเวลาเครื่องเป็น UTC — สั่งเวลาไทยให้ Builder แปลง

        
ระบบดูพัง แต่ curl แล้วปกติprobe ล้มเหลว ≠ ระบบล้มเหลว — ทดสอบผ่าน LINE จริงก่อนสรุป
