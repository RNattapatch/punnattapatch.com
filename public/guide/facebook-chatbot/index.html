งานนี้มี 3 ช่วง รู้ไว้ก่อนจะได้วางแผนถูก

ขั้น 1–6

30–40 นาที · บอทเริ่มตอบได้

ช่วงนี้บอทตอบเฉพาะคุณกับคนในทีมที่เพิ่มชื่อไว้ ทำได้เลยวันนี้ ไม่ต้องรอใครอนุมัติ

ขั้น 7

สัปดาห์–เดือน · ยืนยันตัวตนธุรกิจ

ใช้เอกสารที่ขึ้นชื่อธุรกิจ ยื่นให้เร็วที่สุดเลยครับ เพราะช่วงนี้รอนานกว่าเพื่อน

ขั้น 8

ไม่กี่วัน–2 สัปดาห์ · ลูกค้าจริงทักได้ทุกคน

ยื่นขออนุมัติกับ Facebook ทำได้หลังผ่านช่วงที่แล้ว

ถ้าธุรกิจยังไม่จดทะเบียน ขั้นที่ 7 จะไปต่อไม่ได้ แต่ยังมีทางเริ่มใช้งานได้วันนี้อยู่ครับ เลื่อนไปอ่านหัวข้อสุดท้ายก่อนตัดสินใจ

ส่วนที่ 1

ขั้นตอนที่คุณกดเอง

ส่วนนี้เป็นเรื่องบัญชีและสิทธิ์ของธุรกิจคุณโดยตรง คนอื่นกดแทนไม่ได้ และไม่ควรให้ใครกดแทนด้วยครับ

ขั้นที่ 1

สร้าง App ใน Meta for Developers

  1. เข้า developers.facebook.com ล็อกอินด้วยบัญชี Facebook ที่เป็นแอดมินของเพจ
  2. มุมขวาบน My Apps → Create App
  3. ตั้งชื่อที่จำง่าย เช่น ร้าน[ชื่อคุณ] Chat Bot
  4. ใส่อีเมลติดต่อ — ใช้อีเมลที่คุณเปิดอ่านจริง เพราะ Facebook ส่งเรื่องสำคัญมาทางนี้
  5. เลือกวัตถุประสงค์ที่เกี่ยวกับ Messenger / จัดการข้อความในเพจ
  6. สร้างเสร็จแล้วจด App ID ไว้ (ตัวเลขยาว ๆ ด้านบนของหน้า)

ขั้นที่ 2

ใส่ลิงก์นโยบายความเป็นส่วนตัว

ไปที่ App settings → Basic แล้วกรอก 4 ช่องนี้

  • Privacy Policy URL — วางลิงก์หน้านโยบายที่ทีมงานทำให้
  • User Data Deletion — เลือก Data Deletion Instructions URL แล้ววางลิงก์หน้าขอลบข้อมูล
  • App Domains — ใส่ชื่อโดเมนของเซิร์ฟเวอร์ (ส่วนที่ลงท้าย .hstgr.cloud)
  • Category — เลือกให้ตรงกับธุรกิจ แล้วกด Save changes

ข้อนี้พลาดกันบ่อยที่สุด

เจ้าหน้าที่ของ Facebook กดลิงก์นี้เข้าไปอ่านเองจริง ๆ ครับ ถ้าเปิดไม่ได้ ต้องล็อกอินก่อน หรือเจอหน้าว่างเปล่า เขาปฏิเสธคำขอทั้งชุด ไม่ใช่แค่ข้อนี้ข้อเดียว วิธีเช็คง่ายที่สุดคือเปิดลิงก์จากมือถือที่ปิด WiFi และไม่ได้ล็อกอิน Facebook ดูสักครั้ง

ขั้นที่ 3

ยืนยันอีเมลติดต่อ

อยู่ในหน้า Basic เดียวกันครับ ดูช่อง Contact Email ถ้ายังไม่มีเครื่องหมายยืนยัน ให้กดส่งอีเมลยืนยันแล้วไปกดลิงก์ในกล่องจดหมาย ปล่อยข้อนี้ค้างไว้เดี๋ยวไปติดขั้นถัดไป

ขั้นที่ 4

เพิ่มสิทธิ์ที่ต้องใช้

ไปที่ App Review → Permissions and features แล้วกด Add ทีละตัว

สิทธิ์ใช้ทำอะไร
pages_messagingตัวหลัก — ให้บอทรับและตอบข้อความในเพจ
pages_manage_metadataตั้งค่าให้เพจส่งข้อความเข้าระบบเราได้
pages_show_listให้ระบบเห็นรายชื่อเพจของคุณตอนเชื่อม
pages_utility_messagingส่งข้อความยืนยันนัดหรือสถานะออเดอร์ นอกเวลา 24 ชม.

สิทธิ์ที่ห้ามกดเพิ่มเด็ดขาด

marketing_messages_messenger กับ paid_marketing_messages สองตัวนี้ Facebook ยกเลิกบริการไปแล้วตั้งแต่ ก.พ. 2569 แต่ปุ่มยังค้างอยู่ในหน้า กดไปก็ใช้ไม่ได้ แถมทำให้เรื่องยุ่งตอนยื่นขออนุมัติ

ขั้นที่ 5

เชื่อมเพจเข้ากับ App

  1. เมนูซ้าย → Messenger → API Settings
  2. หัวข้อ Access Tokens กด Add or Remove Pages
  3. เลือกเพจของคุณ แล้วอนุญาตสิทธิ์ทั้งหมดที่ระบบขอ
  4. กลับมาหน้าเดิม จะเห็นชื่อเพจพร้อมปุ่ม Generate Token
  5. กด Generate แล้วคัดลอกรหัสส่งให้ทีมงาน

รหัสนี้คือกุญแจบ้าน

ใครได้รหัสนี้ไป ส่งข้อความหาลูกค้าทุกคนในนามเพจคุณได้ทันที ส่งทางช่องทางส่วนตัวเท่านั้นนะครับ อย่าโพสต์ อย่าส่งในกลุ่ม และถ้าสงสัยเมื่อไหร่ว่าหลุด ให้กลับมาหน้านี้กด Generate ใหม่ รหัสเก่าจะใช้ไม่ได้ทันที

ขั้นที่ 6

ต่อท่อรับข้อความ (Webhooks)

  1. ในหน้า Messenger → API Settings เลื่อนหาหัวข้อ Webhooks → กด Add Callback URL
  2. กรอก Callback URL และ Verify Token ที่ทีมงานให้ — ต้องตรงกันเป๊ะทุกตัวอักษร
  3. กด Verify and save ถ้าขึ้นเขียวแปลว่าต่อติดแล้ว (ถ้าไม่ผ่าน แจ้งทีมงาน อย่าเดาแก้เอง)
  4. กด Add Subscriptions ข้างชื่อเพจ แล้วติ๊ก 8 รายการนี้
messages                messaging_postbacks
messaging_optins        messaging_referrals
messaging_handovers     message_reads
message_deliveries      messaging_policy_enforcement

ตัวสุดท้าย messaging_policy_enforcement สำคัญกว่าที่หลายคนคิดครับ มันคือตัวที่ Facebook ใช้เตือนเราเวลาส่งข้อความผิดกติกา ถ้าไม่ติ๊กไว้ วันหนึ่งโดนลงโทษขึ้นมาจะไม่รู้เลยว่าเพราะอะไร

จากนั้นไปที่ App roles → Roles เพิ่มตัวคุณเองและคนในทีมที่จะช่วยทดสอบเป็น Tester

ถึงตรงนี้บอทตอบได้แล้ว

ลองทักเพจดูได้เลยครับ แต่บอทจะตอบเฉพาะบัญชีที่มีชื่ออยู่ใน App roles ส่วนคนนอกทักมายังเงียบอยู่ ถ้าอยากให้ลูกค้าจริงทักได้ ต้องทำขั้น 7 กับ 8 ต่อ

ขั้นที่ 7

ยืนยันตัวตนธุรกิจ

ขั้นนี้รอนานที่สุดในทั้งหมด ยื่นทันทีเลยครับ แล้วปล่อยให้มันเดินไปเงียบ ๆ ระหว่างที่เราใช้งานทดสอบกันไปด้วย

  1. เข้า business.facebook.com เลือกหรือสร้าง Business portfolio ของธุรกิจคุณ
  2. Business settings → Business info กรอกให้ครบ: ชื่อตามกฎหมาย · ที่อยู่ · เบอร์โทร · เว็บไซต์
  3. Business settings → Accounts → Apps กด Add แล้วเลือก App ที่สร้างไว้ในขั้นที่ 1 (ข้อนี้คนลืมบ่อย และเป็นเงื่อนไขบังคับ)
  4. Business settings → Accounts → Pages กด Add แล้วเลือกเพจของคุณ (ถ้าเพิ่มไม่ได้ ขึ้น error หรือหาเพจไม่เจอ อ่านส่วนที่ 2)
  5. Security Centre เริ่ม Business verification แล้วอัปโหลดเอกสาร

เอกสารที่ Facebook รับ — ต้องขึ้นชื่อธุรกิจ ไม่ใช่ชื่อบุคคล

  • หนังสือรับรองบริษัท หรือใบทะเบียนพาณิชย์
  • เอกสารภาษีของกิจการ เช่น ภ.พ.20
  • สเตทเมนต์บัญชีธนาคารในนามธุรกิจ
  • ใบแจ้งค่าน้ำค่าไฟใช้ยืนยันได้แค่ที่อยู่กับเบอร์ ยืนยันชื่อธุรกิจไม่ได้

จุดที่ร้านเล็กมักติด

ร้านที่ยังไม่จดทะเบียนพาณิชย์ และรับเงินเข้าบัญชีส่วนตัว จะยืนยันไม่ผ่านครับ เพราะเอกสารทุกใบขึ้นชื่อบุคคล ไม่ใช่ชื่อร้าน ต่อให้คุณเป็นเจ้าของคนเดียวก็ตาม ทางแก้คือไปจดทะเบียนพาณิชย์ที่สำนักงานเขตหรือเทศบาล หรือเปิดบัญชีธนาคารในนามร้านก่อน

ขั้นที่ 8

ยื่นขออนุมัติ (App Review)

ทำได้หลังยืนยันธุรกิจผ่านแล้วเท่านั้น

  1. App Review → Permissions and features กด Request advanced access ที่ pages_messaging
  2. เขียนอธิบายว่าใช้ทำอะไร เขียนตรง ๆ เช่น "ตอบคำถามลูกค้าเรื่องสินค้าและราคาในเพจของร้านโดยอัตโนมัติ"
  3. อัดวิดีโอหน้าจอ ให้เห็นครบตั้งแต่เปิดเพจ ทักข้อความ จนบอทตอบกลับ
  4. ส่งแล้วรอผล ปกติไม่กี่วันถึงสองสัปดาห์

ตอนยื่น ระบบต้องเปิดใช้งานได้จริง และเจ้าหน้าที่ต้องกดทดสอบตามได้ ถ้าเข้าไม่ได้หรือขึ้น error จะถูกปฏิเสธทั้งชุด นัดกับทีมงานให้ระบบพร้อมก่อนกดส่งนะครับ

ส่วนที่ 2

เพิ่มเพจเข้า portfolio ไม่ได้ ทำยังไง

ปัญหาที่เจอบ่อยที่สุดในขั้นที่ 7 โดยเฉพาะเพจที่เพิ่งเปิดใหม่ ข้ามหัวข้อนี้ไปได้ถ้าคุณเพิ่มเพจสำเร็จแล้ว

หลักที่ต้องเข้าใจก่อน: เพจหนึ่งอยู่ได้แค่ portfolio เดียว

ถ้าเพจถูกผูกไว้ที่ไหนแล้ว การกด Add จะไม่มีทางสำเร็จ ต่อให้กดกี่ครั้งก็ตาม ต้องปลดจากที่เดิมก่อน หรือใช้วิธีขอสิทธิ์แทนการยึดเป็นเจ้าของ

สาเหตุที่เป็นไปได้ เรียงจากที่เจอบ่อยสุด

#สาเหตุเกิดขึ้นได้ยังไง
1เพจไปอยู่ portfolio อื่นแล้วโดยไม่รู้ตัวถ้าตอนสร้างเพจคุณล็อกอินอยู่ใน Business Suite ของบัญชีธุรกิจเก่า หรือของเอเจนซี่ที่เคยจ้าง เพจจะไปอยู่ที่นั่นตั้งแต่วินาทีแรกที่สร้าง
2สิทธิ์ที่มีไม่ใช่สิทธิ์ควบคุมเต็มเพจยุคใหม่แยก Facebook access (ควบคุมเต็ม) ออกจาก Task access (ทำงานได้บางอย่าง) ถ้ามีแค่แบบหลัง จะเพิ่มเข้า portfolio ไม่ได้ แม้หน้าจอจะขึ้นว่าเป็นแอดมิน
3เพจเพิ่งสร้าง ยังใหม่เกินไปFacebook ระบุเรื่องนี้ไว้เป็นสาเหตุข้อแรกในเอกสารทางการ เพจที่เพิ่งเปิดมีช่วงเวลาที่ยังผูกเข้า portfolio ไม่ได้
4Portfolio ยังไม่ผ่านการยืนยันธุรกิจบัญชีธุรกิจที่ยังไม่ยืนยันมีเพดานจำนวนสินทรัพย์ที่ถือได้ ชนเพดานเมื่อไหร่ก็เพิ่มอะไรไม่ได้อีก
5Portfolio โดนจำกัดสิทธิ์อยู่ถ้าบัญชีธุรกิจโดนระงับเรื่องนโยบาย จะเพิ่มสินทรัพย์ใหม่ไม่ได้เลยจนกว่าจะเคลียร์
6ยังไม่ได้เปิด 2FA หรือไม่ได้เป็นแอดมินทั้งสองฝั่งต้องเป็นแอดมินทั้งของเพจและของบัญชีธุรกิจ ด้วยโปรไฟล์ Facebook เดียวกัน และเปิดยืนยันตัวตนสองชั้นไว้

เช็คก่อนว่าติดข้อไหน ใช้เวลา 3 นาที

  1. เข้าเพจของคุณ ไปที่ Settings → Page access
  2. มองหาหัวข้อที่พูดถึง Business portfolios หรือผู้ที่ควบคุมเพจผ่านบัญชีธุรกิจ
    • ถ้ามีชื่อบัญชีธุรกิจอื่นโผล่มา แปลว่าเจอต้นเหตุแล้ว ตรงกับสาเหตุข้อ 1
    • ถ้าว่างเปล่า ปัญหาน่าจะอยู่ที่สิทธิ์หรือความใหม่ของเพจ คือข้อ 2 หรือ 3
  3. ดูช่อง People with Facebook access ว่าชื่อคุณอยู่ในกลุ่มควบคุมเต็ม หรือแค่ Task access

ทางแก้ตามสาเหตุ

ติดข้อไหนทำยังไง
เพจอยู่บัญชีธุรกิจเก่า ที่คุณยังเข้าถึงได้เข้าบัญชีเก่า ไปที่ Business settings → Pages กด Remove เพจออก แล้วค่อยกลับมา Add ที่บัญชีใหม่
เพจอยู่บัญชีธุรกิจที่เข้าไม่ได้แล้วใช้ปุ่ม Request access แทนการ Add เจ้าของเดิมจะได้รับคำขอให้กดอนุมัติ ถ้าติดต่อไม่ได้จริง ๆ ต้องเปิดเรื่องกับ Meta Business Support
สิทธิ์ไม่พอให้คนที่เป็นเจ้าของเพจเลื่อนสิทธิ์คุณเป็น Facebook access — full control แล้วรอสักครู่ให้ระบบอัปเดตก่อนลองใหม่
เพจใหม่เกินไปรอแล้วลองใหม่ ระหว่างนี้ทำอย่างอื่นไปก่อนได้ เช่นกรอกข้อมูลธุรกิจให้ครบ
ยังไม่ยืนยันธุรกิจเริ่มยื่นยืนยันธุรกิจได้เลย ยังไงก็ต้องทำอยู่แล้วตามขั้นที่ 7

สถานการณ์ทำได้ไหม

        
          
ลูกค้าทักมา แล้วตอบภายใน 24 ชม.ได้ ตอบได้เต็มที่ ไม่มีค่าใช้จ่าย

          
เกิน 24 ชม. แล้วอยากตามลูกค้าต่อบอทยิงไม่ได้ ต้องคนจริงพิมพ์เอง

อยากดึงลูกค้าเก่ากลับมาต้องซื้อโฆษณา Click-to-Messenger

ทางที่ 1

        
ใช้แบบผู้ทดสอบไปก่อน

เริ่มได้วันนี้ ไม่มีค่าใช้จ่ายเพิ่ม
