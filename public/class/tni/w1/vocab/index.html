สัปดาห์ที่ 1 ทบทวน

การ์ดศัพท์ทั้งหลักสูตร

วันนี้คุณแค่ผ่านตาไว้ก่อน แต่ละคำเราจะลงลึกในสัปดาห์ที่ AI เริ่มใช้คำนั้นจริง

สัปดาห์ที่ 1 (วันนี้)

ไฟล์และโฟลเดอร์

ไฟล์คือเอกสารหนึ่งชิ้น โฟลเดอร์คือแฟ้มที่เก็บไฟล์หลายชิ้นไว้ด้วยกัน และ AI จะเปิดได้เฉพาะโฟลเดอร์ที่คุณอนุญาต

สัปดาห์ที่ 1

Markdown

ไฟล์ข้อความที่ใช้ # แบ่งหัวข้อ นามสกุลไฟล์คือ .md เปิดอ่านได้ทุกเครื่อง

สัปดาห์ที่ 1

Context window

โต๊ะที่ AI ใช้วางข้อมูล มีพื้นที่จำกัด ไฟล์ยิ่งยาวยิ่งกินที่บนโต๊ะ

สัปดาห์ที่ 1

Token

ชิ้นเล็กๆ ที่ AI หั่นข้อความไว้นับ คำไทย 1 คำอาจเป็นหลายชิ้น

สัปดาห์ที่ 1

Model กับ Harness

Model คือคน Harness คือที่ทำงานของ AI ได้แก่ กฎ ไฟล์ เครื่องมือ และสิทธิ์รอบตัวคนคนนั้น

สัปดาห์ที่ 1

Connector และ MCP

Connector คือตัวเชื่อมที่ให้ AI อ่านระบบอื่นที่คุณอนุญาต เช่น อีเมล ปฏิทิน และไฟล์ในไดรฟ์ ส่วน MCP คือมาตรฐานกลางที่ใช้สร้างตัวเชื่อมแบบนี้

สัปดาห์ที่ 1

CLI, Terminal และ Bash

CLI คือการสั่งคอมพิวเตอร์ด้วยการพิมพ์ Terminal คือหน้าต่างที่ใช้พิมพ์ และ Bash คือภาษาคำสั่งที่พิมพ์ลงไป คุณจึงควรอ่านคำสั่งที่ AI ขอรันก่อนกดอนุญาต

สัปดาห์ที่ 1

สัปดาห์ที่ 2

API key

รหัสลับที่โปรแกรมใช้ยืนยันตัวตนกับบริการ ใครได้ไปก็ใช้บริการในนามคุณได้

สัปดาห์ที่ 2

ENV และไฟล์ .env

ที่เก็บค่าลับ เช่น API key แยกไว้นอกไฟล์งาน เพื่อไม่ให้หลุดไปตอนแชร์ไฟล์

สัปดาห์ที่ 2

คำขอในแชทกับสิทธิ์ของระบบ

การพิมพ์บอก AI ว่าห้ามลบเป็นแค่คำขอ แต่สิทธิ์ที่ระบบตั้งไว้คือสิ่งที่กันได้จริง

สัปดาห์ที่ 2

Prompt injection

ข้อความแอบแฝงในไฟล์หรือเว็บที่หลอกให้ AI ทำตามคำสั่งของคนอื่นแทนคุณ

สัปดาห์ที่ 2

สัปดาห์ที่ 4

หน้าบ้าน กลางบ้าน หลังบ้าน (Frontend / Backend)

หน้าบ้านคือหน้าจอที่ผู้ใช้เห็นและกด กลางบ้านคือส่วนที่รับคำขอไปทำงานและเก็บกุญแจ หลังบ้านคือที่เก็บข้อมูล

สัปดาห์ที่ 4

Deploy

การนำงานที่ทำในเครื่องขึ้นไปให้คนอื่นเปิดใช้ได้จริง

สัปดาห์ที่ 4

Git

สมุดบันทึกทุกครั้งที่แก้ไฟล์ คุณย้อนกลับไปฉบับก่อนหน้าได้เสมอ

สัปดาห์ที่ 4

สัปดาห์ที่ 5

Database ตาราง และคีย์

Database คือที่เก็บข้อมูลเป็นตาราง ส่วนคีย์คือรหัสไม่ซ้ำที่ใช้ชี้แต่ละแถว

สัปดาห์ที่ 5

SQL

ภาษาที่ใช้ถามข้อมูลจากตาราง เช่น SELECT เลือกคอลัมน์ WHERE กรองแถว GROUP BY จัดกลุ่ม และ JOIN เชื่อมสองตาราง

สัปดาห์ที่ 5

CSV

ไฟล์ตารางแบบข้อความที่คั่นแต่ละช่องด้วยจุลภาค เปิดใน Excel ได้

สัปดาห์ที่ 5

JSON

รูปแบบข้อความที่เก็บข้อมูลเป็นคู่ชื่อกับค่า ระบบต่างๆ ใช้ส่งข้อมูลหากัน

สัปดาห์ที่ 5

API

ช่องทางที่โปรแกรมหนึ่งใช้ขอข้อมูลหรือสั่งงานอีกโปรแกรมหนึ่ง

สัปดาห์ที่ 5

สัปดาห์ที่ 6

Trigger

เหตุการณ์ที่สั่งให้งานเริ่มเอง เช่น มีไฟล์ใหม่เข้ามาในโฟลเดอร์

สัปดาห์ที่ 6

cron

ตัวตั้งเวลาให้งานรันเองตามรอบ เช่น ทุกวัน 8 โมงเช้า ใช้บน Mac และ Linux

สัปดาห์ที่ 6

Windows Task Scheduler

ตัวตั้งเวลาให้งานรันเองตามรอบบนเครื่อง Windows

สัปดาห์ที่ 6

สคริปต์ Python

ไฟล์คำสั่งภาษา Python ที่ให้คอมพิวเตอร์ทำงานซ้ำแทนคุณ

สัปดาห์ที่ 6

Log

บันทึกว่าระบบทำอะไรไปบ้างและเมื่อไร คุณใช้ดูตอนงานพัง

สัปดาห์ที่ 6

สัปดาห์ที่ 11

Backup

สำเนาข้อมูลที่เก็บไว้อีกที่ เผื่อของจริงเสียหรือหาย

สัปดาห์ที่ 11

Monitoring

การเฝ้าดูว่าระบบยังทำงานอยู่ และแจ้งเตือนเมื่อระบบล่ม

สัปดาห์ที่ 11

SSH

วิธีเข้าไปสั่งงานคอมพิวเตอร์อีกเครื่องผ่านอินเทอร์เน็ตอย่างปลอดภัย สัปดาห์นั้นแค่รู้จักชื่อก็พอ

สัปดาห์ที่ 11
