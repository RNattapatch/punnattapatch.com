Bonus builder · พร้อมใช้ในคลาส

LINE Agent
Building Prompt

ให้ผู้เรียนเปิดโฟลเดอร์ AI Office ใน Codex Desktop หรือ Claude Code Desktop แล้ววาง Prompt นี้ครั้งเดียว Agent จะเดินงานตั้งแต่ตรวจเครื่องจนถึงทดสอบส่ง LINE จริง

  • ใช้ OA ทดสอบหรือ OA ภายในเท่านั้น
  • เก็บ Token ในไฟล์ env ไม่วางในแชต
  • ส่งตรงหา LINE ส่วนตัว ไม่เปิด broadcast

ฉบับเต็มมีขั้นตอนความปลอดภัย, LINE MCP และ Morning briefing
