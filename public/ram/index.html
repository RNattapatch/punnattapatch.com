คุยกับ Agent ของผมใน LINE

สไลด์อยู่บนหน้านี้แล้ว ไม่ต้องแอดก็โหลดได้ · ถ้าอยากถามต่อเรื่องที่สงสัยจากคลาส ทักเข้ามาได้ คำถามไหนที่ต้องให้ผมตอบเอง บอทจะส่งต่อให้

ทักถามต่อทาง LINE

บอทตัวนี้ตอบจากฐานข้อมูลธุรกิจของผม ไม่ใช่จากความจำของโมเดล — ความต่างอยู่ที่ Context ไม่ใช่ที่โมเดลฉลาดขึ้น

ข้อมูลอะไรถูกเก็บบ้าง

  • หน้านี้ไม่มี form ไม่ขอ email ไม่มี login และไม่มี script ติดตามบุคคล
  • เทส 90/10 คำนวณในเครื่องคุณ ไม่ส่งไปไหน ไม่บันทึก
  • ถ้า add LINE OA: LINE จะให้ชื่อกับรูปโปรไฟล์ตามปกติของแพลตฟอร์ม และข้อความที่พิมพ์จะถูกเก็บเพื่อให้บอทตอบต่อได้
  • ติดต่อขอลบข้อมูลได้ทาง LINE OA เดียวกัน

หน้านี้สร้างยังไง

หน้านี้เขียนด้วย coding agent จาก brief ของคลาส แล้วให้ agent อีกตัวตรวจซ้ำ — route, เนื้อหา, แบบทดสอบ 90/10, contrast และหน้าจอมือถือ · คนตัดสินใจว่าอะไรขึ้นหน้าเว็บและอะไรไม่ขึ้น นี่คือ human gate ที่พูดถึงในช่วงที่ 3
