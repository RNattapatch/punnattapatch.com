Bug 1 Fixed

🔥 Hot button resets — เกิดเพราะ apply() override click ทุกครั้งที่ store refresh → เพิ่ม tempDirty flag แก้ได้

Bug 2 — ต้องเลือก design

Pipeline stage ไม่มี UI ให้ตั้ง — stage ถูก derive จาก timestamps + pipeline_status field แต่ไม่มี selector ให้ user กดได้โดยตรง

เพิ่ม Pipeline Stage select เป็น field แรกใน Command Center panel — ค่า: New Lead / Discovery / Proposal Sent / Walkthrough (Won/Lost ยังใช้ EditDeal modal เดิม)
